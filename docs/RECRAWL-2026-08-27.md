## Not a GSC submission

`https://paqar.my/llms.txt` is not an indexable page and does not go through
URL Inspection. It is fetched directly by answer engines, so it updates on
deploy with no action needed. Worth checking once after release:

```
curl -s https://paqar.my/llms.txt | grep -c "does not currently sell"
```

**Expect `0`.** If it returns `1`, `JOMCHECK_ENABLED` is not `true` in the
Vercel environment — the file is generated from the same gate the checkout
uses, so a `1` there means the add-on is genuinely switched off, not that the
copy drifted.
